# sophiaramahi.de

Verbindliches Ausgangsrepository fuer den kompletten Neubau von `sophiaramahi.de`.

## Projektziel

Die bestehende WordPress-Seite wird durch eine eigenstaendige, dunkle und filmische Astro-Website ersetzt. Das Projekt verbindet:

- Sophias reale Arbeiten und Medien
- Leistungs- und Projektseiten mit klarer interner Verlinkung
- eine belastbare lokale SEO-Architektur fuer Duesseldorf und ausgewaehlte NRW-Standorte
- kontrollierte GSAP-Animationen
- einen einfachen, niedrigschwelligen Kontaktweg
- eine statische, performante Bereitstellung auf Vercel
