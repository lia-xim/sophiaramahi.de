# Public repository notice

This repository intentionally contains the source of the public portfolio website at `sophiaramahi.de`.

## Included by design

- public business and legal contact details required by the website
- optimized portfolio images and the public showreel used by the deployed site
- website copy, design sources, Astro code, and deployment configuration

## Not included

- credentials, API keys, access tokens, private keys, or production secrets
- `.env` files or local Vercel metadata
- high-resolution source media or private project archives
- private client records, contracts, invoices, or unpublished correspondence

Local environment files and deployment metadata are ignored by Git. Before adding new media, verify copyright, publication consent, credits, music rights, and personality rights. Do not commit secrets; use the deployment provider's encrypted environment variables instead.

Contributions are not accepted unless arranged with the project owner. Public visibility does not make this an open-source project; see `LICENSE.md`.
